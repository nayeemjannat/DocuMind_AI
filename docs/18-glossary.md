# 18 — Glossary

- **API:** Application Programming Interface; the backend endpoints used by the frontend.
- **Authentication:** Verifying who the user is.
- **Authorization:** Verifying what that user is allowed to access.
- **Chunk:** A bounded passage extracted from a document for retrieval.
- **Embedding:** A numeric vector representing semantic information in text.
- **Grounded answer:** An answer supported by retrieved source passages.
- **Ingestion:** The process of validating, parsing, chunking, embedding, and indexing a document.
- **Lease:** A time-bounded claim on a background job that can expire after a worker crash.
- **MVP:** Minimum Viable Product; the smallest version that demonstrates the intended value.
- **pgvector:** PostgreSQL extension for storing and searching vector embeddings.
- **RAG:** Retrieval-Augmented Generation; retrieving relevant information and using it to inform an LLM answer.
- **RLS:** Row-Level Security; database policies that restrict rows by user/context.
- **Service-role key:** A privileged backend credential; must never be exposed to the browser.
- **Vector search:** Finding chunks by embedding similarity.
- **Citation precision:** The share of returned citations that actually support the claims they are attached to.
- **Abstention:** Explicitly declining to answer when evidence is insufficient.
